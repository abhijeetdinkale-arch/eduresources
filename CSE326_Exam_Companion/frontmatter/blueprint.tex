\textbf{Difficulty Level Standard}:
\begin{itemize}[leftmargin=8mm]
  \item \textbf{Easy (50\%)}: Direct syntax recognition, definition identifiers, core tags, basic operator outputs.
  \item \textbf{Medium (30\%)}: Specificity calculations, box-model arithmetic, scope nesting, loop break/continue traces.
  \item \textbf{Hard (20\%)}: Complex closures, regex pattern edge-cases, prototype inheritance, event propagation nuances.
\end{itemize}
