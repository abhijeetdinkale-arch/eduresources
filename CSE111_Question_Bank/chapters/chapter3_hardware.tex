\begin{expbox}[Selected Question Explanations]
\begin{itemize}[leftmargin=5mm]
    \item \textbf{Q.2 (B):} GPUs excel in deep learning and 3D graphics because their architecture features thousands of parallel arithmetic units executing identical operations simultaneously.
    \item \textbf{Q.3 (C):} The Program Counter (PC) register tracks program flow by maintaining the memory address of the next instruction to fetch.
    \item \textbf{Q.6 (B):} DRAM stores data in tiny capacitor cells that bleed charge and must be refreshed every few milliseconds; SRAM uses flip-flops and retains data statically while powered.
    \item \textbf{Q.10 (B):} SSDs have zero moving mechanical components, making them immune to mechanical head crashes and substantially faster than magnetic HDDs.
    \item \textbf{Q.14 (B):} In computing IEC binary prefixes, $1\text{ KiB} = 2^{10} = 1,024\text{ bytes}$.
    \item \textbf{Q.21 (B):} Laser printers use an electrostatic charging drum and heat-fused powdered toner to produce crisp text pages at high speed.
    \item \textbf{Q.33 (C):} Internal CPU registers operate at the same speed as the execution units and sit at the very pinnacle of the speed hierarchy.
    \item \textbf{Q.50 (B):} Solid-state flash cells can endure a finite number of program/erase write cycles; wear-leveling spreads writes evenly across cells to prevent premature failure.
\end{itemize}
\end{expbox}
