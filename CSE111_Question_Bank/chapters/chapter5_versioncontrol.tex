\begin{expbox}[Selected Question Explanations]
\begin{itemize}[leftmargin=5mm]
    \item \textbf{Q.3 (B):} Git is a distributed VCS; every cloned local repository holds the entire commit history, allowing full offline operation.
    \item \textbf{Q.9 (B):} The staging area (or index) serves as a preview buffer where developers select exactly what changes to include in the next commit.
    \item \textbf{Q.15 (A):} The \texttt{.gitignore} text file specifies wildcards and directory patterns (like logs or build artifacts) that Git should deliberately omit from tracking.
    \item \textbf{Q.20 (B):} A Git branch is simply a lightweight, movable pointer to a commit, facilitating parallel feature development.
    \item \textbf{Q.36 (C):} Saving a file in an editor only updates the working directory on disk. It must be explicitly staged (\texttt{git add}) and committed (\texttt{git commit}) to enter Git history.
    \item \textbf{Q.37 (B):} \texttt{git commit} only saves changes locally; \texttt{git push} is required to transfer those commits to a remote hosting platform like GitHub.
\end{itemize}
\end{expbox}
