# INT108: Python Programming — Comprehensive University Study & Exam Mastery Guide

## Overview
This repository contains the complete LaTeX source files and build automation for the **INT108: Python Programming** university textbook, specifically engineered for first-year engineering students at Lovely Professional University (LPU).

## Syllabus Coverage (Units 1 to 6)
- **Part I / Unit 1**: Programming Environment, Variables, Expressions & Statements
- **Part II / Unit 2**: Conditional Statements, Iterative Statements & Algorithms
- **Part III / Unit 3**: Functions, Scope, Modules & Recursion
- **Part IV / Unit 4**: Strings, Lists, Tuples & Dictionaries (Compound Data Structures)
- **Part V / Unit 5**: Object-Oriented Programming (Classes, Objects, Inheritance & Encapsulation)
- **Part VI / Unit 6**: File Handling, Exception Handling & Regular Expressions
- **Part VII**: Master Python Syntax, Methods & Standard Library Cheatsheet
- **Part VIII**: Cross-Unit Practical Coding Challenges (15 Multi-Concept Problems)
- **Part IX**: Full-Length University Mock Examination Papers (2 Sets of 100 Marks with Solutions)

## Building the Book
To compile the complete textbook into PDF:
```bash
make
```
This produces `main.pdf` and `INT108.pdf`.
