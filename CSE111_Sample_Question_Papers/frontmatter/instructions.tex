\section*{Overview of Assessment Components}
This volume contains the complete official evaluation suite for \textbf{CSE111: Orientation to Computing}, organized into 16 distinct model test papers across four major academic milestones:

\begin{enumerate}[leftmargin=8mm, label=\textbf{\Roman*.}]
    \item \textbf{Continuous Assessment 1 (CA-1) Suite [Sets A, B, C, D]}:
    \begin{itemize}[leftmargin=6mm]
        \item \textbf{Syllabus Scope:} Unit 1 (Computer Languages) and Unit 2 (Computer Fundamentals).
        \item \textbf{Question Format:} 25 Multiple-Choice Questions (1 mark each). Total = 25 Marks.
        \item \textbf{Time Allowed:} 45 Minutes.
    \end{itemize}

    \item \textbf{Mid-Term Examination Suite [Sets A, B, C, D]}:
    \begin{itemize}[leftmargin=6mm]
        \item \textbf{Syllabus Scope:} Unit 1 (Computer Languages), Unit 2 (Computer Fundamentals), and Unit 3 (Computer Hardware).
        \item \textbf{Question Format:} 30 Multiple-Choice Questions (1 mark each). Total = 30 Marks.
        \item \textbf{Time Allowed:} 60 Minutes.
    \end{itemize}

    \item \textbf{Continuous Assessment 2 (CA-2) Suite [Sets A, B, C, D]}:
    \begin{itemize}[leftmargin=6mm]
        \item \textbf{Syllabus Scope:} Unit 4 (Number Systems) and Unit 5 (Version Control).
        \item \textbf{Question Format:} 25 Multiple-Choice Questions (1 mark each). Total = 25 Marks.
        \item \textbf{Time Allowed:} 45 Minutes.
    \end{itemize}

    \item \textbf{End-Term Examination Suite [Sets A, B, C, D]}:
    \begin{itemize}[leftmargin=6mm]
        \item \textbf{Syllabus Scope:} Comprehensive coverage across all six units (Units 1 to 6).
        \item \textbf{Question Format:} 30 Multiple-Choice Questions (1 mark each). Total = 30 Marks.
        \item \textbf{Time Allowed:} 90 Minutes.
    \end{itemize}
\end{enumerate}

\section*{Difficulty Calibration Standard}
In direct alignment with the university previous-year question pattern:
\begin{itemize}[leftmargin=6mm]
    \item \textbf{60\% Direct Recall / Definitions:} Testing core terminology, acronyms, and direct facts.
    \item \textbf{25--30\% Basic Conceptual Understanding:} Understanding system behavior, purpose of hardware units, and Git commands.
    \item \textbf{10\% Simple Application:} Standard base conversions (binary, octal, hex) and simple tracing.
    \item \textbf{0\% Hard / Competitive Traps:} No multi-step calculations, deep architecture proofs, or confusing double negatives.
\end{itemize}
