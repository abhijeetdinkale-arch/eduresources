\begin{expbox}[Technical Solutions --- End-Term Set C]
\begin{itemize}[leftmargin=5mm]
    \item \textbf{Q.12 (B):} SRAM uses flip-flops, providing ultra-low access latency, which makes it the standard choice for CPU cache.
    \item \textbf{Q.15 (C):} In Hexadecimal, $\text{A}=10, \text{B}=11, \text{C}=12, \text{D}=13$.
    \item \textbf{Q.18 (A):} $11001010_2$ in 4-bit sets: $\underbrace{1100}_{\text{C}}\;\underbrace{1010}_{\text{A}} = (\text{CA})_{16}$.
    \item \textbf{Q.20 (B):} $0.101_2 = 1(0.5) + 0(0.25) + 1(0.125) = 0.625_{10}$.
    \item \textbf{Q.25 (A):} Deep learning is defined by the use of multi-layered deep artificial neural networks.
\end{itemize}
\end{expbox}
