\mcqitem{4}{The stored-program architecture where instructions and data reside in common memory was formulated in 1945 by:}{Blaise Pascal}{John von Neumann}{Charles Babbage}{Alan Turing}

\mcqitem{5}{What electronic switching component was used in first-generation computers (1940--1956)?}{Transistors}{Vacuum tubes}{Integrated circuits}{Microprocessors}

\mcqitem{6}{The fourth generation of computers (starting in 1971) was defined by the development of:}{Vacuum tubes}{Microprocessors}{Magnetic drums}{Relays}

\mcqitem{7}{Which CPU component performs arithmetic calculations and logical comparisons?}{Control Unit}{Arithmetic Logic Unit (ALU)}{Program Counter}{Address Bus}

\mcqitem{8}{Which system bus is unidirectional and transmits physical memory addresses from the CPU to memory chips?}{Data Bus}{Address Bus}{Control Bus}{Power Bus}

\mcqitem{10}{The CPU register that stores the memory address of the next instruction to fetch is the:}{Instruction Register (IR)}{Program Counter (PC)}{Accumulator}{Stack Pointer}

\mcqitem{11}{Dynamic RAM (DRAM) differs from Static RAM (SRAM) because DRAM:}{Is non-volatile}{Requires periodic electrical refreshing to retain data}{Is faster than SRAM}{Is used in CPU cache}

\mcqitem{12}{Solid-State Drives (SSDs) are faster and more shock-resistant than Hard Disk Drives (HDDs) because:}{SSDs use spinning platters}{SSDs use flash memory chips with no moving parts}{SSDs use lasers}{SSDs are connected to USB}

\mcqitem{13}{What is the base (radix) of the Hexadecimal number system?}{8}{10}{12}{16}

\mcqitem{14}{In the hexadecimal number system, what decimal value does the letter 'C' represent?}{10}{11}{12}{13}

\mcqitem{15}{What is the decimal equivalent of the binary number $(1011)_2$?}{9}{11}{13}{15}

\mcqitem{16}{How many binary bits correspond directly to a single Octal digit?}{2 bits}{3 bits}{4 bits}{8 bits}

\mcqitem{17}{What is the octal equivalent of the binary number $(110101)_2$?}{$(55)_8$}{$(65)_8$}{$(35)_8$}{$(71)_8$}

\mcqitem{18}{What is the hexadecimal equivalent of the binary number $(10101111)_2$?}{$(\text{AF})_{16}$}{$(\text{FA})_{16}$}{$(\text{BF})_{16}$}{$(\text{AE})_{16}$}

\mcqitem{19}{Who created the Git version control system in 2005?}{Dennis Ritchie}{Linus Torvalds}{James Gosling}{Guido van Rossum}

\mcqitem{20}{What kind of version control system is Git?}{Centralized}{Distributed}{Single-user}{Manual}

\mcqitem{26}{All existing commercial AI assistants (like Siri, ChatGPT, and Google Gemini) are classified as:}{Artificial General Intelligence (AGI)}{Narrow AI}{Super AI}{Self-conscious AI}
