\begin{expbox}[Technical Solutions --- End-Term Set D]
\begin{itemize}[leftmargin=5mm]
    \item \textbf{Q.1 (B):} Compilers translate the whole program before execution and detect syntax errors early.
    \item \textbf{Q.13 (C):} In Hexadecimal, $\text{A}=10, \text{B}=11, \text{C}=12, \text{D}=13, \text{E}=14$.
    \item \textbf{Q.14 (C):} $1110_2 = 8 + 4 + 2 + 0 = 14_{10}$.
    \item \textbf{Q.15 (A):} $111010_2$ in 3-bit groups: $\underbrace{111}_{7}\;\underbrace{010}_{2} = (72)_8$.
    \item \textbf{Q.17 (B):} $(2\text{B})_{16} = 2(16) + 11 = 43_{10}$.
    \item \textbf{Q.27 (B):} Hallucination is when an LLM fabricates false facts fluently.
    \item \textbf{Q.28 (B):} Multimodal models like Gemini natively process and understand text, images, and audio.
\end{itemize}
\end{expbox}
