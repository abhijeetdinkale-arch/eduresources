\chapter{End-Term Examination Suite (Comprehensive)}
\label{chap:endterm_suite}
\noindent
The End-Term Examination is the comprehensive objective test covering all six modules of \textbf{CSE111: Orientation to Computing}:
\begin{itemize}[leftmargin=8mm]
    \item \textbf{Unit 1:} Computer Languages (Machine, Assembly, HLL, Compilers, Interpreters, Development Cycle)
    \item \textbf{Unit 2:} Computer Fundamentals (Von Neumann Architecture, Generations 1--5, Functional Units, System Buses)
    \item \textbf{Unit 3:} Computer Hardware (CPU vs. GPU, Peripherals, Memory Hierarchy, DRAM vs. SRAM, ROM, SSDs)
    \item \textbf{Unit 4:} Number Systems (Binary, Octal, Decimal, Hexadecimal, Direct Grouping Conversions)
    \item \textbf{Unit 5:} Version Control (Git Distributed Model, Three-Tree Architecture, Branching, GitHub)
    \item \textbf{Unit 6:} Modern AI Trends and Tools (AI/ML/DL, Generative AI, LLMs, Research Tools, Prompt Engineering)
\end{itemize}
Each comprehensive paper consists of \textbf{30 MCQs (1 mark each, Total = 30 Marks, Time Allowed = 90 Minutes)}. Complete Answer Keys and technical rationales follow each set.
