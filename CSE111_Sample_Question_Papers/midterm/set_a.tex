\section{Mid-Term Examination --- Set A}
\label{sec:midterm_set_a}

\ExamHeader{Mid-Term Examination}{A}{60 Minutes}{30 Marks}{Units 1, 2 \& 3 (Languages, Fundamentals \& Hardware)}

\noindent
\textbf{Instructions:} All 30 questions are compulsory. Each question carries 1 mark. Select the single best answer.

\vspace{3mm}

\mcqitem{1}{Which language is executed directly by the CPU without any intermediate translation?}{Assembly language}{Machine language}{C language}{Python}

\mcqitem{2}{In assembly language, the operation symbol \texttt{MOV} is known as a/an:}{Operand}{Mnemonic}{Register}{Variable}

\mcqitem{3}{A translator that translates and executes high-level source code line-by-line during runtime is a/an:}{Compiler}{Interpreter}{Assembler}{Linker}

\mcqitem{4}{Which phase of compilation converts character streams into tokens such as keywords and identifiers?}{Lexical Analysis}{Syntax Analysis}{Semantic Analysis}{Code Generation}

\mcqitem{5}{What is the primary role of the Linker in the C/C++ compilation pipeline?}{To write source code}{To combine object files with library functions into a final executable}{To load the program into memory}{To execute machine code}

\mcqitem{6}{Which system software loads the binary executable from disk into RAM to start execution?}{Compiler}{Loader}{Assembler}{Editor}

\mcqitem{7}{What does an assembler do during its first pass over assembly source code?}{Emits machine code bytes}{Builds a symbol table recording label names and memory addresses}{Executes instructions}{Formats the output}

\mcqitem{8}{An error that occurs when a program compiles successfully but produces incorrect output is a:}{Syntax error}{Logic error}{Compile-time error}{Linker error}

\mcqitem{9}{What is the correct sequence of the CPU instruction execution cycle?}{Decode $\rightarrow$ Execute $\rightarrow$ Fetch $\rightarrow$ Store}{Fetch $\rightarrow$ Decode $\rightarrow$ Execute $\rightarrow$ Store}{Store $\rightarrow$ Fetch $\rightarrow$ Execute $\rightarrow$ Decode}{Execute $\rightarrow$ Fetch $\rightarrow$ Decode $\rightarrow$ Store}

\mcqitem{10}{Who proposed the stored-program architecture in 1945 where instructions and data share the same memory?}{Blaise Pascal}{John von Neumann}{Charles Babbage}{Herman Hollerith}

\mcqitem{11}{First-generation computers (1940--1956) utilized which primary electronic switching component?}{Transistors}{Vacuum tubes}{Integrated circuits}{Microprocessors}

\mcqitem{12}{Second-generation computers (1956--1963) replaced vacuum tubes with:}{Microprocessors}{Transistors}{Integrated circuits}{Magnetic drums}

\mcqitem{13}{Integrated circuits (ICs) on silicon chips were the defining technology of which computer generation?}{First generation}{Second generation}{Third generation}{Fourth generation}

\mcqitem{14}{Which company launched the world's first commercial single-chip microprocessor (the 4004) in 1971?}{IBM}{Intel}{Apple}{Microsoft}

\mcqitem{15}{Fifth-generation computing primarily emphasizes which of the following technological domains?}{Vacuum tubes}{Artificial Intelligence and massive parallel processing}{Mechanical calculators}{Punched card tabulators}

\mcqitem{16}{The principle that incorrect input data leads to incorrect output information is abbreviated as:}{FIFO}{GIGO}{LIFO}{DMA}

\mcqitem{17}{Which CPU component performs arithmetic calculations and logical comparisons?}{Control Unit}{Arithmetic Logic Unit (ALU)}{Instruction Register}{Program Counter}

\mcqitem{18}{Which system bus is unidirectional, carrying memory addresses from the CPU to memory chips?}{Data Bus}{Address Bus}{Control Bus}{Power Bus}

\mcqitem{19}{Which of the following is volatile primary memory?}{ROM}{Hard disk}{RAM}{SSD}

\mcqitem{20}{A dedicated microcontroller built inside a washing machine or microwave to perform a fixed control task is an:}{Supercomputer}{Embedded computer}{Mainframe}{Workstation}

\mcqitem{21}{Why are GPUs preferred over CPUs for training deep learning neural networks?}{GPUs have higher clock frequencies for single threads}{GPUs have thousands of smaller cores for massive parallel arithmetic}{GPUs eliminate RAM}{GPUs are non-volatile}

\mcqitem{22}{The CPU register that stores the memory address of the next instruction to be fetched is the:}{Instruction Register (IR)}{Program Counter (PC)}{Accumulator}{Stack Pointer}

\mcqitem{23}{The CPU register that holds the instruction currently being executed or decoded is the:}{Program Counter (PC)}{Instruction Register (IR)}{Memory Address Register}{Status Register}

\mcqitem{24}{Which level of CPU cache is typically the fastest and closest to the CPU processing core?}{L3 Cache}{L2 Cache}{L1 Cache}{Virtual memory}

\mcqitem{25}{Dynamic RAM (DRAM) differs from Static RAM (SRAM) because DRAM:}{Is non-volatile}{Requires periodic electrical refreshing}{Is used for CPU cache}{Is made of optical discs}

\mcqitem{26}{Which memory retains its contents permanently even after the computer is powered off?}{DRAM}{SRAM}{ROM}{L1 Cache}

\mcqitem{27}{Solid-State Drives (SSDs) are faster and more shock-resistant than Hard Disk Drives (HDDs) because:}{SSDs use rotating magnetic platters}{SSDs use flash memory with no moving mechanical parts}{SSDs use water-cooling}{SSDs are connected to USB}

\mcqitem{28}{How many bits are in one standard Byte?}{4}{8}{16}{32}

\mcqitem{29}{A touchscreen display is classified as:}{An input device only}{An output device only}{Both an input and an output device}{A secondary storage medium}

\mcqitem{30}{Which software tool is required to allow the operating system to communicate with a specific peripheral device like a printer?}{Compiler}{Device driver}{Text editor}{Linker}

\begin{expbox}[Technical Solutions --- Mid-Term Set A]
\begin{itemize}[leftmargin=5mm]
    \item \textbf{Q.4 (A):} Lexical analysis scans the source characters and generates tokens for the compiler.
    \item \textbf{Q.10 (B):} John von Neumann's architecture holds programs and data in the same unified memory.
    \item \textbf{Q.21 (B):} GPUs feature thousands of cores executing identical arithmetic instructions on large data arrays in parallel.
    \item \textbf{Q.22 (B):} The Program Counter (PC) stores the address of the next instruction to fetch.
    \item \textbf{Q.27 (B):} SSDs have no mechanical read heads or spinning disks, making them durable and fast.
\end{itemize}
\end{expbox}
