\section{Mid-Term Examination --- Set D}
\label{sec:midterm_set_d}

\ExamHeader{Mid-Term Examination}{D}{60 Minutes}{30 Marks}{Units 1, 2 \& 3 (Languages, Fundamentals \& Hardware)}

\noindent
\textbf{Instructions:} All 30 questions are compulsory. Each question carries 1 mark. Select the single best answer.

\vspace{3mm}

\mcqitem{1}{Which language level provides maximum hardware control and execution speed but lacks portability?}{High-Level Language}{Machine Language}{Python}{Visual Basic}

\mcqitem{2}{In an assembly instruction \texttt{ADD R1, R2}, what is the operation word \texttt{ADD}?}{An operand}{A mnemonic opcode}{A label}{A directive}

\mcqitem{3}{A compiler differs from an interpreter because a compiler:}{Translates line-by-line at runtime}{Translates the entire program into machine/object code before execution}{Requires no CPU}{Executes only in the cloud}

\mcqitem{4}{The compilation stage that checks whether keywords and operators form valid grammatical statements is:}{Lexical Analysis}{Syntax Analysis}{Semantic Analysis}{Loading}

\mcqitem{5}{A missing semicolon in a C++ source file causes which type of error?}{Compile-time syntax error}{Runtime error}{Logic error}{Linker warning}

\mcqitem{6}{What is the primary role of the preprocessor in the C language?}{Translates C code into assembly}{Expands macros and header inclusions before compilation}{Loads binary into RAM}{Executes code}

\mcqitem{7}{What does an assembler do in its first pass?}{Emits binary machine code}{Records symbol names and memory addresses in a symbol table}{Links object files}{Tests program logic}

\mcqitem{8}{Which step of the program development cycle involves formalizing the problem requirements, inputs, and outputs?}{Problem Definition}{Coding}{Testing}{Maintenance}

\mcqitem{9}{An informal description of an algorithm written in plain English mixed with programming-style logic is:}{Pseudocode}{Machine code}{Bytecode}{Microcode}

\mcqitem{10}{Who is celebrated as the "Father of the Computer" for proposing the Analytical Engine?}{Blaise Pascal}{Charles Babbage}{Herman Hollerith}{John von Neumann}

\mcqitem{11}{The 1945 stored-program architecture where code and data reside in common memory was formulated by:}{John von Neumann}{Charles Babbage}{Alan Turing}{Linus Torvalds}

\mcqitem{12}{First-generation computers (1940--1956) were characterized by which physical switching devices?}{Transistors}{Vacuum tubes}{Integrated circuits}{Microprocessors}

\mcqitem{13}{Second-generation computers (1956--1963) introduced which electronic component, reducing heat and physical size?}{Vacuum tubes}{Transistors}{Integrated circuits}{Microprocessors}

\mcqitem{14}{Integrated circuits (ICs) combining multiple components on a single silicon chip marked which generation?}{First generation}{Second generation}{Third generation}{Fifth generation}

\mcqitem{15}{The Intel 4004 (1971) was the world's first commercial:}{Single-chip microprocessor}{Mainframe computer}{Operating system}{Laser printer}

\mcqitem{16}{Fifth-generation computing research focuses heavily on:}{Relay switches}{Artificial Intelligence and parallel computing}{Vacuum tubes}{Mechanical punch cards}

\mcqitem{17}{The computer characteristic GIGO reminds us that:}{Fast computers never make mistakes}{Output correctness depends strictly on input accuracy}{Hard drives lose data}{Compilers fix logic errors}

\mcqitem{18}{Which CPU component performs mathematical calculations ($+, -$) and logical comparisons (\texttt{AND}, \texttt{OR})?}{Control Unit}{Arithmetic Logic Unit (ALU)}{Instruction Register}{Address Bus}

\mcqitem{19}{Which system bus is unidirectional and carries physical memory addresses from the CPU to memory chips?}{Data Bus}{Address Bus}{Control Bus}{Power Bus}

\mcqitem{20}{Which system bus carries command signals like Memory Read, Memory Write, and Interrupts?}{Data Bus}{Address Bus}{Control Bus}{Expansion Bus}

\mcqitem{21}{Which memory type provides ultra-fast temporary storage located directly inside the CPU chip?}{Registers}{Hard disk}{Flash drive}{Optical disc}

\mcqitem{22}{Why is primary RAM called "volatile" memory?}{It gets physically hot}{It loses its stored data as soon as power is disconnected}{It cannot be overwritten}{It uses spinning disks}

\mcqitem{23}{Which type of software includes operating systems like Windows and Linux?}{Application software}{System software}{Utility spreadsheet}{Firmware patch}

\mcqitem{24}{Computers designed to process continuous physical measurements (like temperature or pressure) are:}{Digital computers}{Analog computers}{Hybrid computers}{Mainframes}

\mcqitem{25}{A computer built directly into an anti-lock braking system (ABS) to perform dedicated real-time control is a/an:}{Supercomputer}{Embedded computer}{Mainframe}{Workstation}

\mcqitem{26}{Why are GPUs preferred over CPUs for training deep learning models?}{GPUs have higher clock speeds for single threads}{GPUs contain thousands of cores designed for parallel matrix operations}{GPUs eliminate the need for RAM}{GPUs are non-volatile}

\mcqitem{27}{The CPU register that stores the memory address of the next instruction to fetch is the:}{Instruction Register (IR)}{Program Counter (PC)}{Accumulator}{Stack Pointer}

\mcqitem{28}{Dynamic RAM (DRAM) is used as main system memory because:}{It uses flip-flops and needs no refresh}{It provides high density at moderate cost, though it requires periodic electrical refreshing}{It is non-volatile}{It is made of magnetic tape}

\mcqitem{29}{Solid-State Drives (SSDs) are faster and more durable than Hard Disk Drives (HDDs) because:}{SSDs have spinning platters}{SSDs use flash memory with no moving mechanical parts}{SSDs use high-power lasers}{SSDs are water-cooled}

\mcqitem{30}{Which input peripheral converts printed text on paper into editable digital characters using OCR?}{Microphone}{Scanner}{Barcode reader}{Touchpad}

\begin{expbox}[Technical Solutions --- Mid-Term Set D]
\begin{itemize}[leftmargin=5mm]
    \item \textbf{Q.3 (B):} Compilers translate the whole program before execution, allowing fast, native execution.
    \item \textbf{Q.5 (A):} Syntax errors are grammar violations detected during the compile phase.
    \item \textbf{Q.18 (B):} The Arithmetic Logic Unit handles all mathematical and Boolean operations.
    \item \textbf{Q.27 (B):} The Program Counter (PC) register holds the address of the next instruction to fetch.
    \item \textbf{Q.29 (B):} SSDs have zero moving mechanical parts, providing silent, fast, and shock-resistant storage.
\end{itemize}
\end{expbox}
