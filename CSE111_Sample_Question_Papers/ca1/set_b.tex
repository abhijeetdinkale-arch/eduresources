\section{Continuous Assessment 1 --- Set B}
\label{sec:ca1_set_b}

\ExamHeader{Continuous Assessment 1}{B}{45 Minutes}{25 Marks}{Unit 1 (Computer Languages) \& Unit 2 (Computer Fundamentals)}

\noindent
\textbf{Instructions:} All 25 questions are compulsory. Each question carries 1 mark. Select the single best answer.

\vspace{3mm}

\mcqitem{1}{Which of the following is a key characteristic of high-level programming languages?}{They use only binary opcodes}{They provide hardware abstraction and human-readable syntax}{They cannot be translated}{They run only on one processor architecture}

\mcqitem{2}{A translator that produces an independent executable object file before running the program is a/an:}{Interpreter}{Compiler}{Debugger}{Text Editor}

\mcqitem{3}{In assembly language instruction \texttt{MOV R1, R2}, what are \texttt{R1} and \texttt{R2}?}{Mnemonics}{CPU Registers}{Immediate constants}{Labels}

\mcqitem{4}{Which compilation phase checks whether expressions follow type compatibility rules?}{Lexical Analysis}{Syntax Analysis}{Semantic Analysis}{Preprocessing}

\mcqitem{5}{Division by zero while running a program is an example of a:}{Syntax error}{Logic error}{Runtime error}{Linker error}

\mcqitem{6}{What is the primary function of an Assembler?}{Translating high-level language to assembly}{Translating assembly language mnemonics into binary machine code}{Running programs line-by-line}{Connecting to the internet}

\mcqitem{7}{Which step in the program development cycle involves using test cases to find and fix bugs?}{Coding}{Testing and Debugging}{Problem Definition}{Documentation}

\mcqitem{8}{A graphical chart that depicts program logic using diamonds, rectangles, and arrows is a:}{Pseudocode}{Flowchart}{Syntax diagram}{Data sheet}

\mcqitem{9}{In an assembler, what occurs during the second pass?}{Recording label addresses}{Generating machine instructions and resolving address references}{Lexical scanning only}{Loading the executable}

\mcqitem{10}{Which language provides direct register-level control while remaining symbolic?}{Machine Language}{Assembly Language}{Python}{HTML}

\mcqitem{11}{Who invented the Pascaline calculating machine in 1642?}{Charles Babbage}{Blaise Pascal}{Herman Hollerith}{Alan Turing}

\mcqitem{12}{The concept of storing both program instructions and working data in the same internal memory is the:}{Babbage concept}{Stored-program principle}{GIGO principle}{RISC principle}

\mcqitem{13}{Which hardware technology was used as the primary internal logic switch in first-generation computers?}{Transistors}{Vacuum tubes}{Integrated circuits}{Microprocessors}

\mcqitem{14}{Which high-level programming languages were widely popularized during the second computer generation?}{Python and Java}{FORTRAN and COBOL}{HTML and SQL}{C\# and Swift}

\mcqitem{15}{The third generation of computing was defined by the introduction of:}{Vacuum tubes}{Discrete relays}{Integrated Circuits (ICs)}{Microcontrollers}

\mcqitem{16}{The Intel 4004, launched in 1971, is celebrated in computing history as the world's first:}{Supercomputer}{Single-chip microprocessor}{Hard disk drive}{Operating system}

\mcqitem{17}{Fifth-generation computing primarily aims to advance systems in:}{Vacuum tube amplification}{Mechanical levers}{Artificial intelligence and parallel computing}{Punched card sorting}

\mcqitem{18}{The computer characteristic that allows it to execute millions of calculations without fatigue is:}{Versatility}{Accuracy}{Diligence}{Automation}

\mcqitem{19}{Which sub-unit of the CPU performs logic operations like \texttt{AND}, \texttt{OR}, and comparisons?}{Control Unit}{Arithmetic Logic Unit (ALU)}{Instruction Register}{Address Bus}

\mcqitem{20}{Which system bus transmits signals such as Memory Read, Memory Write, and Clock Timing?}{Data Bus}{Address Bus}{Control Bus}{Serial Bus}

\mcqitem{21}{Which of the following is volatile primary memory?}{ROM}{Hard Disk}{RAM}{Flash Drive}

\mcqitem{22}{Firmware that initializes computer hardware during startup (BIOS/UEFI) is stored in:}{RAM}{ROM}{Cache}{Secondary Storage}

\mcqitem{23}{Software that directly manages computer hardware and provides a platform for user applications is:}{Application Software}{System Software}{Shareware}{Freeware}

\mcqitem{24}{Computers designed to process discrete binary digits ($0$ and $1$) are classified as:}{Analog computers}{Digital computers}{Hybrid computers}{Mechanical engines}

\mcqitem{25}{A server computer's primary role in a network is to:}{Act as a game controller}{Provide shared resources, services, and data to client computers}{Operate washing machine motors}{Eliminate RAM}

\begin{expbox}[Technical Solutions --- CA-1 Set B]
\begin{itemize}[leftmargin=5mm]
    \item \textbf{Q.2 (B):} Compilers translate entire source files to machine/object code, allowing standalone execution without re-translation.
    \item \textbf{Q.4 (C):} Semantic analysis verifies type rules, such as checking if operands match operators.
    \item \textbf{Q.9 (B):} In pass 2, an assembler translates instructions into machine code using the symbol table created in pass 1.
    \item \textbf{Q.12 (B):} Stored-program principle allows programs to be loaded into RAM dynamically just like data.
    \item \textbf{Q.18 (C):} Diligence is the ability of computers to perform monotonous, repetitive tasks without fatigue.
    \item \textbf{Q.21 (C):} RAM loses all stored data when power is disconnected (volatile).
\end{itemize}
\end{expbox}
