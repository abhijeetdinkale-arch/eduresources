\section{Continuous Assessment 1 --- Set D}
\label{sec:ca1_set_d}

\ExamHeader{Continuous Assessment 1}{D}{45 Minutes}{25 Marks}{Unit 1 (Computer Languages) \& Unit 2 (Computer Fundamentals)}

\noindent
\textbf{Instructions:} All 25 questions are compulsory. Each question carries 1 mark. Select the single best answer.

\vspace{3mm}

\mcqitem{1}{In which language does each instruction typically represent a 1-to-1 correspondence with a machine instruction using mnemonics?}{Assembly Language}{Python}{Java}{SQL}

\mcqitem{2}{Which tool translates an entire high-level program and reports compile-time errors prior to runtime?}{Interpreter}{Compiler}{Operating System}{Text Editor}

\mcqitem{3}{In an assembly instruction \texttt{ADD R1, R2, R3}, \texttt{R1}, \texttt{R2}, and \texttt{R3} are:}{Opcodes}{Operands / Registers}{Preprocessors}{Labels}

\mcqitem{4}{The phase in compilation that transforms source code into optimized lower-level instructions is:}{Code generation \& optimization}{Lexical analysis}{Preprocessing}{Linking}

\mcqitem{5}{A program containing a logic error will:}{Fail during compilation with a syntax error}{Compile and run, but output wrong results}{Freeze the CPU indefinitely}{Refuse to load into RAM}

\mcqitem{6}{What is the primary role of the operating system's loader?}{Translating high-level source code to assembly}{Placing the executable image into physical RAM to initiate execution}{Compiling Java bytecode}{Formatting hard drives}

\mcqitem{7}{What does the preprocessor in C/C++ handle before compilation begins?}{Executing the program}{Header file inclusions (\texttt{\#include}) and macro replacements}{Linking object files}{Syntax tree generation}

\mcqitem{8}{Which step of the program development cycle involves formalizing the inputs, outputs, and requirements of the problem?}{Problem Definition}{Coding}{Testing}{Maintenance}

\mcqitem{9}{A step-by-step description of an algorithm using plain English mixed with programming-like structures is:}{Pseudocode}{Machine code}{Bytecode}{Microcode}

\mcqitem{10}{During which phase of a two-pass assembler are memory addresses resolved and machine code emitted?}{First pass}{Second pass}{Pre-pass}{Post-pass}

\mcqitem{11}{Who is recognized as the "Father of the Computer" for conceiving the Analytical Engine?}{Blaise Pascal}{Charles Babbage}{Herman Hollerith}{John von Neumann}

\mcqitem{12}{John von Neumann's 1945 paper established the foundation for:}{Stored-program digital computer architecture}{The internet}{Quantum computing}{Microprocessor lithography}

\mcqitem{13}{Which electronic component defined first-generation computing systems?}{Vacuum tubes}{Transistors}{Integrated circuits}{Microprocessors}

\mcqitem{14}{Which of the following was a notable second-generation computer improvement over first-generation systems?}{Use of transistors resulting in smaller size, less heat, and greater reliability}{Elimination of all programming languages}{Introduction of the World Wide Web}{Use of mechanical gears}

\mcqitem{15}{Integrated circuits (ICs), combining multiple electronic components on a single chip, marked the:}{First generation}{Second generation}{Third generation}{Fifth generation}

\mcqitem{16}{The first single-chip commercial microprocessor, the Intel 4004, launched which computer generation?}{Third generation}{Fourth generation}{Second generation}{Fifth generation}

\mcqitem{17}{Current computing research emphasizing parallel multi-core architectures, neural networks, and AI belongs to:}{Second generation}{Third generation}{Fifth generation}{First generation}

\mcqitem{18}{The computer characteristic GIGO stands for:}{General Input, General Output}{Garbage In, Garbage Out}{Global Instruction, Global Operation}{Guaranteed Input, Guaranteed Output}

\mcqitem{19}{Which CPU unit directs instruction execution and coordinates data flow between memory and the ALU?}{Arithmetic Logic Unit}{Control Unit (CU)}{System Clock}{Hard drive}

\mcqitem{20}{Which system bus transmits physical memory addresses from the processor to memory chips?}{Data Bus}{Address Bus}{Control Bus}{Power Bus}

\mcqitem{21}{Which of the following is an example of non-volatile primary storage used for startup firmware?}{RAM}{ROM}{L1 Cache}{L2 Cache}

\mcqitem{22}{Device drivers are classified as:}{System software}{Application software}{Spreadsheet tools}{Optical hardware}

\mcqitem{23}{Which class of computer is specifically designed to support high-volume transaction processing for airlines and banks?}{Microcontroller}{Mainframe computer}{Workstation}{Tablet}

\mcqitem{24}{A microcontroller combines which components on a single silicon chip?}{Processor, memory, and I/O interfaces}{Only a screen and keyboard}{Only a cooling fan}{A power supply and hard disk}

\mcqitem{25}{A computer designed to perform a single dedicated task, such as engine fuel-injection control, is a:}{General-purpose computer}{Special-purpose / Embedded computer}{Mainframe computer}{Supercomputer}

\begin{expbox}[Technical Solutions --- CA-1 Set D]
\begin{itemize}[leftmargin=5mm]
    \item \textbf{Q.2 (B):} Compilers translate code prior to execution and catch syntax errors ahead of runtime.
    \item \textbf{Q.6 (B):} The operating system loader allocates memory space and places the compiled executable into RAM.
    \item \textbf{Q.11 (B):} Charles Babbage designed the Analytical Engine, establishing basic computer organization concepts.
    \item \textbf{Q.16 (B):} The Intel 4004 (1971) initiated the 4th generation of microprocessors.
    \item \textbf{Q.24 (A):} A microcontroller is a complete "system on a chip" incorporating CPU, RAM, ROM, and I/O pins.
\end{itemize}
\end{expbox}
