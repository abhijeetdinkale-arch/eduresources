\section{Continuous Assessment 1 --- Set C}
\label{sec:ca1_set_c}

\ExamHeader{Continuous Assessment 1}{C}{45 Minutes}{25 Marks}{Unit 1 (Computer Languages) \& Unit 2 (Computer Fundamentals)}

\noindent
\textbf{Instructions:} All 25 questions are compulsory. Each question carries 1 mark. Select the single best answer.

\vspace{3mm}

\mcqitem{1}{Which programming language does not require any translator before direct execution by the processor?}{Assembly Language}{Machine Language}{C}{Java}

\mcqitem{2}{What is the binary representation of instructions in machine language composed of?}{Bits 0 and 1}{Alphanumeric strings}{XML tags}{English keywords}

\mcqitem{3}{An immediate feedback execution model where statements are evaluated one-by-one is provided by a/an:}{Compiler}{Interpreter}{Assembler}{Linker}

\mcqitem{4}{Which part of the compiler identifies syntax errors like missing semicolons or unmatched parentheses?}{Lexical Analysis}{Syntax Analysis}{Semantic Analysis}{Code Generation}

\mcqitem{5}{Connecting external function definitions from libraries (e.g., standard math library) to an object file is done by the:}{Loader}{Linker}{Preprocessor}{Editor}

\mcqitem{6}{Which system software puts the compiled and linked binary file into main memory to begin execution?}{Linker}{Loader}{Compiler}{Debugger}

\mcqitem{7}{Why are assembly language programs less portable than high-level programs?}{They are too large in size}{They are tied directly to a specific processor's instruction set architecture}{They cannot execute arithmetic}{They lack compilers}

\mcqitem{8}{Testing a program with input value $0$ when calculating division is called:}{Syntax checking}{Boundary value testing}{Optimization}{Semantic scanning}

\mcqitem{9}{Which stage of the CPU instruction cycle retrieves the binary instruction from RAM into the CPU?}{Execute}{Fetch}{Decode}{Store}

\mcqitem{10}{Which step of the program development cycle involves ongoing bug fixes and functional enhancements after deployment?}{Analysis}{Maintenance}{Coding}{Design}

\mcqitem{11}{Who proposed the mechanical Analytical Engine with basic concepts of input, processing, memory, and output in the 1830s?}{Blaise Pascal}{Charles Babbage}{Herman Hollerith}{John von Neumann}

\mcqitem{12}{Herman Hollerith used punched cards to process data for which major event?}{1890 US Census}{Apollo 11 mission}{1945 World War II codebreaking}{1971 microprocessor design}

\mcqitem{13}{First-generation computers were plagued by which physical drawback?}{Very low power consumption}{Excessive heat production and frequent vacuum tube burnouts}{Excessive microchip speed}{Complete portability}

\mcqitem{14}{Second-generation computers (1956--1963) saw the introduction of:}{Vacuum tubes}{Transistors}{Microprocessors}{Artificial Intelligence}

\mcqitem{15}{Which generation of computers introduced user interaction through keyboards and monitors rather than paper punch cards?}{First generation}{Third generation}{Second generation}{Fifth generation}

\mcqitem{16}{The fourth generation of computers began around 1971 with the invention of the:}{Vacuum tube}{Microprocessor}{Transistor}{Analytical Engine}

\mcqitem{17}{Fifth-generation computers are distinguished by an emphasis on:}{Natural language processing and Artificial Intelligence}{Relay switches}{Punched card tabulators}{Analog vacuum tubes}

\mcqitem{18}{The capability of a computer to handle diverse tasks like spreadsheets, video playback, and gaming is:}{Diligence}{Versatility}{Accuracy}{Storage}

\mcqitem{19}{Which CPU unit directs data flow between registers, the ALU, and system buses?}{Control Unit (CU)}{Arithmetic Logic Unit}{Heat sink}{Storage unit}

\mcqitem{20}{Which system bus is bidirectional and transfers data words between the CPU and memory?}{Address Bus}{Data Bus}{Control Bus}{Serial Bus}

\mcqitem{21}{Which memory type provides ultra-fast temporary storage located directly inside the CPU chip?}{Registers}{Hard drive}{Flash drive}{Optical disc}

\mcqitem{22}{Why is RAM considered volatile memory?}{It catches fire easily}{It loses its stored data as soon as power is disconnected}{It cannot be overwritten}{It is mechanical}

\mcqitem{23}{Which type of software includes web browsers, photo editors, and spreadsheet programs?}{System software}{Application software}{Firmware}{Device driver}

\mcqitem{24}{Computers that combine both analog measurement and digital processing capabilities are:}{Digital computers}{Hybrid computers}{Supercomputers}{Microcontrollers}

\mcqitem{25}{A computer built directly into an anti-lock braking system (ABS) to perform dedicated real-time control is a/an:}{Supercomputer}{Embedded computer}{Mainframe}{Workstation}

    \item \textbf{Q.7 (B):} Assembly language mnemonics map 1-to-1 with the specific hardware opcodes of that processor model.
