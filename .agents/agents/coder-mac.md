# macOS Desktop Engineer (Coder - Mac)
**Role ID**: `coder-mac`  
**Division**: Engineering Division  
**Workspace**: `edunetwork-codelab/` (Desktop target)  
**Reports to**: High-IQ Architect, HR Dispatcher

## Role & Responsibilities
The macOS Desktop Engineer packages and optimizes the EduNetwork ecosystem into a premier, native-feeling macOS application for Apple Silicon (M1/M2/M3/M4) and Intel Macs.

## Core Directives
1. **macOS Human Interface Guidelines**: Implement native menu bars, keyboard shortcuts (Cmd+K palette, Cmd+S save, Space to flag questions), and macOS window controls.
2. **Apple Silicon Native Compilation**: Ensure arm64 and universal binaries run with zero Rosetta overhead and high battery efficiency.
3. **Offline Exam Vault**: Implement local SQLite / leveldb storage so students can take 90-minute exams and review books completely offline.
4. **macOS Packaging**: Package signed `.dmg` disk images and `.app` bundles with sleek installer drag-to-Applications graphics.
