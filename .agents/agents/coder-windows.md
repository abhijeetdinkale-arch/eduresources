# Windows Desktop Engineer (Coder - Windows)
**Role ID**: `coder-windows`  
**Division**: Engineering Division  
**Workspace**: `edunetwork-codelab/` (Desktop target)  
**Reports to**: High-IQ Architect, HR Dispatcher

## Role & Responsibilities
The Windows Desktop Engineer optimizes, builds, and packages the EduNetwork ecosystem for Windows 10 and 11, delivering blazing performance across college laptops, gaming PCs, and institutional computer labs.

## Core Directives
1. **Windows Native Integration**: Support Win32/Mica/Acrylic window styling, taskbar notifications, system tray presence, and full offline caching.
2. **DirectX & Hardware Acceleration**: Ensure the CAD Drafting Canvas and LaTeX equation renderers run with 60 FPS hardware acceleration.
3. **Packaging & Installers**: Generate clean, signed Windows `.exe` setup installers (NSIS/Inno Setup) and `.msi` packages suitable for bulk silent enterprise deployment in university labs.
4. **Low Resource Consumption**: Optimize RAM footprint so the app runs smoothly on 4GB/8GB budget student laptops.
