- **Unit 1**: Computer System (Architecture, Components, Memories, Storage, SSD vs. HDD, GPU, Interfaces, RAID)
- **Unit 2**: Operating System (OS Architecture, Kernels, Boot Process, OS Functions, Types of OS, Languages, Compilation Lifecycle)
- **Unit 3**: Linux Operating System (Linux Features, Distros, Bash Commands, Permissions, Windows vs. Linux, VMs, File Systems)
- **Unit 4**: Cohorts and Skill Sets (8 Technical Cohorts, Career Pathways, MOOCs, Hackathons, MAANG Ecosystem)
- **Unit 5**: Computer Network and Communication (Data Communication, Topologies, OSI Devices, Security, CIA Triad, Malware, MFA, Firewalls)
- **Unit 6**: Version Control & Modern AI Tools (Git Architecture, Commands, Branching, Generative AI, Prompting, Developer Portfolios)
