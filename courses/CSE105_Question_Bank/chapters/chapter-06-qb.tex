\section{Technical Viva-Voce Questions \& Conceptual Answers}

\subsection*{Q1. Explain the syntactic differences between BRE and ERE regarding quantifiers and grouping.}
\begin{vivasol}
Under **Basic Regular Expressions (BRE)**, metacharacters like \texttt{+}, \texttt{?}, \texttt{|}, \texttt{(}, and \texttt{\{} are treated as literal characters unless escaped with a backslash (\texttt{\textbackslash+}, \texttt{\textbackslash?}, \texttt{\textbackslash|}, \texttt{\textbackslash( \textbackslash)}, \texttt{\textbackslash{ \textbackslash}}).
Under **Extended Regular Expressions (ERE)**, these characters are treated as active metacharacters natively: \texttt{+} (one or more), \texttt{?} (zero or one), \texttt{|} (alternation), \texttt{( )} (grouping), and \texttt{\{m,n\}} (repetition count).
\end{vivasol}

\subsection*{Q2. Construct a pipeline that finds the 5 most frequent HTTP response status codes in a web server log.}
\begin{vivasol}
Assuming standard Combined Log Format where the HTTP status code is column 9:
\begin{clibox}
$ awk '{print $9}' access.log | sort | uniq -c | sort -rn | head -n 5
\end{clibox}
\end{vivasol}

\begin{practicalbox}{6.1 --- Industrial Log Stream Analytics}
\textbf{Objective:} Process a simulated Apache web access log, extract client IP addresses, deduplicate, and sort by request volume.
\begin{clibox}
$ cat << 'EOF' > web.log
192.168.1.10 - - [22/Oct/2026:08:00:01] "GET /index.html" 200 4500
10.0.0.5 - - [22/Oct/2026:08:00:02] "POST /api/login" 401 512
192.168.1.10 - - [22/Oct/2026:08:00:03] "GET /style.css" 200 1200
192.168.1.10 - - [22/Oct/2026:08:00:04] "GET /logo.png" 200 8900
10.0.0.5 - - [22/Oct/2026:08:00:05] "POST /api/login" 200 1024
EOF

$ cut -d' ' -f1 web.log | sort | uniq -c | sort -rn
      3 192.168.1.10
      2 10.0.0.5
\end{clibox}
\end{practicalbox}
