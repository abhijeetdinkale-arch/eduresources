\begin{cheatbox}{Ex Command-Line Mode Reference}
\begin{itemize}[leftmargin=1.5em]
    \item \texttt{:w}: Save buffer to disk. \texttt{:w filename}: Save As.
    \item \texttt{:wq} or \texttt{:x} or \texttt{ZZ}: Save changes and exit editor.
    \item \texttt{:q!}: Force quit immediately, discarding unsaved modifications.
    \item \texttt{/pattern}: Search forward for regex pattern (\texttt{n} next, \texttt{N} previous).
    \item \texttt{?pattern}: Search backward for regex pattern.
    \item \texttt{:\%s/old/new/g}: Global replacement across the entire file.
    \item \texttt{:\%s/old/new/gc}: Global replacement with interactive confirmation prompt.
    \item \texttt{:set number} / \texttt{:set nonu}: Toggle line numbering.
\end{itemize}
\end{cheatbox}
