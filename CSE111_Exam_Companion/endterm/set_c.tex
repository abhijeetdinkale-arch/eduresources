\subsection*{Detailed Technical Solutions}

\begin{solutionbox}[Key Comprehensive Technical Explanations]
\textbf{Q.5 (Ans: A)} Bus bandwidth is the product of bus width in bytes and clock frequency. A 64-bit bus carries $64 / 8 = 8\text{ bytes}$ per transfer cycle. At $800\text{ MHz} = 800 \times 10^6\text{ cycles/s}$, Bandwidth $= 8\text{ bytes} \times 800 \times 10^6 = 6.4 \times 10^9\text{ bytes/s} = 6.4\text{ GB/s}$.\\[2mm]
\textbf{Q.22 (Ans: A)} In a mesh network of $N = 8$ nodes, each node requires $N - 1 = 7$ links to every other node. Total links $= \frac{N(N - 1)}{2} = \frac{8 \times 7}{2} = 28\text{ links}$.\\[2mm]
\textbf{Q.28 (Ans: A)} While \texttt{git diff} shows unstaged modifications in the working tree compared to the index, \texttt{git diff --staged} (or \texttt{git diff --cached}) displays the exact staged patch changes that are currently prepared to be recorded into the next commit snapshot.\\[2mm]
\textbf{Q.29 (Ans: A)} In Zero-Shot prompting, the model relies purely on its pre-trained parametric knowledge and instruction tuning without receiving in-context demonstration pairs. When tasks require specialized formatting or domain constraints, Few-Shot prompting provides $k$ examples to condition the autoregressive generation.\\[2mm]
\textbf{Q.30 (Ans: A)} AI coding assistants process surrounding code context (open files, preceding functions, imports, docstrings) as prompt context in an LLM trained on billions of lines of open-source software, predicting likely next tokens to synthesize complete functions, boilerplate, and unit tests in real time.
\end{solutionbox}
