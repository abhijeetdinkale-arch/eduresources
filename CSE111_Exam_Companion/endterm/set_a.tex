\subsection*{Detailed Technical Solutions}

\begin{solutionbox}[Key Comprehensive Technical Explanations]
\textbf{Q.3 (Ans: A)} RAID 5 distributes single parity across all member drives. For $N = 5$ drives of $2\text{ TB}$, usable capacity is $(N - 1) \times S = (5 - 1) \times 2\text{ TB} = 8\text{ TB}$.\\[2mm]
\textbf{Q.12 (Ans: A)} Octal 7 is $\texttt{rwx}$ ($4+2+1$), while octal 5 is $\texttt{r-x}$ ($4+0+1$). \texttt{chmod 755} assigns read, write, and execute permissions to the file owner, and read and execute permissions to group members and all others.\\[2mm]
\textbf{Q.27 (Ans: A)} Git's three-tier local architecture consists of: (1) \textit{Working Directory} (untracked/modified files on disk), (2) \textit{Staging Area / Index} (snapshot prepared for commit via \texttt{git add}), and (3) \textit{Git Repository} (committed snapshot history permanently stored in \texttt{.git/objects} via \texttt{git commit}).\\[2mm]
\textbf{Q.28 (Ans: A)} \texttt{git merge feature} creates a 3-way merge commit with two parent commits, preserving the exact historical topology of the feature branch. In contrast, \texttt{git rebase main} takes the unique commits from \texttt{feature}, temporarily rewinds to \texttt{main}, and reapplies the commits on top of \texttt{main}, creating new commit hashes and a linear project history.\\[2mm]
\textbf{Q.29 (Ans: A)} Chain-of-Thought (CoT) prompting prompts the autoregressive transformer model to generate intermediate reasoning tokens prior to outputting the final conclusion. Because transformers predict each token conditioned on all preceding tokens, generating reasoning steps enriches the context window and substantially reduces logical deduction errors.
\end{solutionbox}
