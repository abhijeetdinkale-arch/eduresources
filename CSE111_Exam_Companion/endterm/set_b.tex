\subsection*{Detailed Technical Solutions}

\begin{solutionbox}[Key Comprehensive Technical Explanations]
\textbf{Q.1 (Ans: A)} Temporal Locality states that if at time $t$ a location is referenced, it is likely to be referenced again at $t + \Delta t$. Modern caching hardware keeps recently referenced blocks in high-speed L1/L2 caches to exploit this behavior in loop iterations and subroutines.\\[2mm]
\textbf{Q.7 (Ans: A)} In Round Robin, if the time quantum $q \ge \max(\text{Burst Times})$, every process completes its CPU burst before its quantum expires. Consequently, processes are executed to completion in the strict order they entered the ready queue, identical to FCFS.\\[2mm]
\textbf{Q.19 (Ans: A)} Quick Sort partitions an array around a chosen pivot. If the pivot consistently yields the most unbalanced partition possible (e.g. 0 elements on one side and $N-1$ on the other, occurring when picking the first or last element of an already sorted array), the recurrence becomes $T(N) = T(N-1) + \Theta(N)$, which sums to $\Theta(N^2)$.\\[2mm]
\textbf{Q.28 (Ans: A)} When Git merges two branches and cannot perform a fast-forward merge, it analyzes the common ancestor (3-way merge). If both branches changed the same region of a file, Git halts the automatic merge, marks the conflicted section with conflict markers (\texttt{<<<<<<<}, \texttt{=======}, \texttt{>>>>>>>}), and requires the developer to resolve the conflict manually before committing.\\[2mm]
\textbf{Q.30 (Ans: A)} Retrieval-Augmented Generation (RAG) combines dense vector search (semantic retrieval over an embedding database) with generative language modeling. The retriever injects authoritative, up-to-date document chunks into the prompt, grounding the LLM's response in verified facts and substantially reducing hallucinations.
\end{solutionbox}
