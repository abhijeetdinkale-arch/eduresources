\subsection*{Detailed Technical Solutions}

\begin{solutionbox}[Key Comprehensive Technical Explanations]
\textbf{Q.2 (Ans: A)} Under IEEE 754 single-precision (32-bit), 1 bit is allocated for sign, 8 bits for exponent (range -126 to +127 with bias 127), and 23 bits for the normalized mantissa fraction, delivering $\approx 7$ decimal digits of precision.\\[2mm]
\textbf{Q.6 (Ans: A)} A Zombie process occurs when a child process terminates execution by calling \texttt{exit()}. The kernel retains its Process Control Block (PCB) entry containing its exit status. Until the parent process reads this status via \texttt{wait()} or \texttt{waitpid()}, the child remains a Zombie in the process table.\\[2mm]
\textbf{Q.15 (Ans: A)} Inodes are local to a specific filesystem partition (filesystem metadata structure). Because different partitions have completely independent Inode tables, an Inode number on partition $A$ has no relation to the same Inode number on partition $B$. Hence, Hard Links cannot cross filesystem boundaries, whereas Symbolic Links (which store textual paths) can.\\[2mm]
\textbf{Q.26 (Ans: A)} In Git, creating a branch does not copy the codebase. Git simply creates a text file inside \texttt{.git/refs/heads/<branch-name>} containing the 40-character hexadecimal SHA-1 hash (plus a newline character $= 41\text{ bytes}$) of the latest commit on that branch. This makes branching virtually instantaneous and lightweight.\\[2mm]
\textbf{Q.29 (Ans: A)} The Self-Attention mechanism computes attention weights between every pair of tokens in a sequence: $\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$. This allows the network to model contextual dependencies across arbitrary distances in constant sequential operations, replacing recurrent loops.
\end{solutionbox}
