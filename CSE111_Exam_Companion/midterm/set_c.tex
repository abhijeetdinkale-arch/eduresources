\subsection*{Detailed Technical Solutions}

\begin{solutionbox}[Key Architectural, Systems \& Linux Explanations]
\textbf{Q.6 (Ans: A)} To update a single data block in RAID 5 without recalculating parity across the entire stripe, the controller computes: $P_{\text{new}} = P_{\text{old}} \oplus D_{\text{old}} \oplus D_{\text{new}}$. This requires 2 read operations ($D_{\text{old}}$ and $P_{\text{old}}$) followed by 2 write operations ($D_{\text{new}}$ and $P_{\text{new}}$), resulting in 4 physical I/Os per write.\\[2mm]
\textbf{Q.14 (Ans: A)} In Banker's Algorithm, the safety state check relies on evaluating whether the remaining resource demand ($\text{Need} = \text{Max} - \text{Allocation}$) can be satisfied by the currently free resources ($\text{Available}$).\\[2mm]
\textbf{Q.15 (Ans: A)} Paging divides virtual address space into fixed-sized pages and physical memory into identical frames. Because any page can be loaded into any free frame regardless of physical contiguity, external fragmentation is completely eliminated. However, internal fragmentation may occur on the final page of a process if the program size is not an exact multiple of the page size.\\[2mm]
\textbf{Q.24 (Ans: A)} In collaborative team directories, the SGID bit on a directory (displayed as \texttt{drwxrwsr-x}) ensures that any file or subfolder created by any team member automatically inherits the group ownership of the parent directory, allowing group members continued read/write access without manual \texttt{chown} commands.\\[2mm]
\textbf{Q.27 (Ans: A)} Signal 9 (\texttt{SIGKILL}) cannot be trapped, handled, or blocked by the destination process. When issued, the operating system kernel terminates the process immediately, cleans up allocated resources, and releases memory frames.
\end{solutionbox}
