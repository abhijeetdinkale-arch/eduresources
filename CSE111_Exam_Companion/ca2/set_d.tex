\subsection*{Detailed Technical Solutions}

\begin{solutionbox}[Key Cohorts \& Networking Explanations]
\textbf{Q.11 (Ans: A)} The Disjoint Set Union (DSU) structure maintains a collection of disjoint sets. Using \textit{Path Compression} in the \texttt{find} operation and \textit{Union by Rank/Size}, any sequence of $M$ operations on $N$ elements takes $O(M \cdot \alpha(N))$ time, where $\alpha$ is the inverse Ackermann function ($\alpha(N) \le 4$ for all practical values in the universe, effectively constant time).\\[2mm]
\textbf{Q.17 (Ans: A)} Single-Mode Fiber uses an extremely narrow core ($\approx 8 - 10\,\mu\text{m}$) matching the wavelength of infrared laser light ($1310\text{ nm}$ or $1550\text{ nm}$). Light travels along a single axial path without reflecting off cladding walls at multiple angles, eliminating intermodal dispersion and enabling transmission distances of dozens of kilometers.\\[2mm]
\textbf{Q.21 (Ans: A)} A \texttt{/28} CIDR prefix has $32 - 28 = 4$ host bits. The total number of IP addresses in the block is $2^4 = 16$. Subtracting the network ID and the broadcast address leaves $16 - 2 = 14$ usable host IPs.\\[2mm]
\textbf{Q.23 (Ans: A)} To simplify router processing and speed up packet forwarding across the Internet backbone, the IPv6 specification established a fixed 40-byte base header (compared to IPv4's variable 20-60 byte header with options) and eliminated the header checksum field (relying on Layer 2 and Layer 4 checksums).\\[2mm]
\textbf{Q.25 (Ans: A)} In a SYN Flood attack, the attacker sends spoofed \texttt{SYN} requests. The server allocates a Transmission Control Block (TCB) in memory and responds with \texttt{SYN-ACK}. Because the attacker never replies with the final \texttt{ACK}, half-open sockets accumulate until the server's SYN backlog is completely exhausted, denying service to legitimate clients. Modern servers mitigate this using SYN Cookies.
\end{solutionbox}
