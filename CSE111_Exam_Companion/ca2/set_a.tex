\subsection*{Detailed Technical Solutions}

\begin{solutionbox}[Key Cohorts \& Networking Explanations]
\textbf{Q.9 (Ans: A)} Binary search repeatedly bisects the search space. Starting with $N$ elements, after $k$ steps the remaining candidates are $N / 2^k$. When $N / 2^k = 1 \implies 2^k = N \implies k = \log_2 N$. Thus, worst-case time complexity is $O(\log N)$.\\[2mm]
\textbf{Q.17 (Ans: A)} In a fully connected mesh network with $N$ nodes, every node must have a dedicated duplex cable to every other node ($N - 1$). Since each physical link connects two nodes, the total number of bidirectional links is $\frac{N(N - 1)}{2} = \frac{10 \times 9}{2} = 45\text{ links}$.\\[2mm]
\textbf{Q.21 (Ans: A)} Hubs operate at OSI Layer 1 as physical-layer repeaters: any incoming bit frame is replicated out of all other ports, causing collisions. Switches operate at Layer 2: they inspect the source MAC address to learn port locations and forward frames strictly to the destination port, eliminating collisions via microsegmentation.\\[2mm]
\textbf{Q.24 (Ans: A)} RFC 1918 defines three private IP ranges for non-routable local traffic: Class A (\texttt{10.0.0.0/8}), Class B (\texttt{172.16.0.0/12}), and Class C (\texttt{192.168.0.0/16}). Routers on the public Internet drop packets containing private IP addresses.\\[2mm]
\textbf{Q.25 (Ans: A)} A \texttt{/24} subnet mask reserves 24 bits for the network identifier and leaves $32 - 24 = 8\text{ bits}$ for host addressing. $2^8 = 256$ total addresses. The first address (\texttt{.0}) is reserved as the Network ID, and the last address (\texttt{.255}) is reserved as the Subnet Directed Broadcast. Hence, usable host addresses $= 256 - 2 = 254$.
\end{solutionbox}
