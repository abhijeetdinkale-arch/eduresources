\subsection*{Detailed Technical Solutions}

\begin{solutionbox}[Key Cohorts \& Networking Explanations]
\textbf{Q.8 (Ans: A)} Under average conditions, a hash function maps keys uniformly across array buckets. With collision resolution (e.g., chaining with short lists or open addressing with low load factor $\alpha < 0.7$), search, insert, and delete operations execute in expected $O(1)$ constant time.\\[2mm]
\textbf{Q.9 (Ans: A)} Merge Sort recursively splits the array into two halves ($2T(N/2)$) and merges them in linear time ($O(N)$). Solving the recurrence $T(N) = 2T(N/2) + O(N)$ using the Master Theorem yields an asymptotically optimal worst-case time complexity of $\Theta(N \log N)$.\\[2mm]
\textbf{Q.20 (Ans: A)} The TCP Three-Way Handshake establishes a reliable bidirectional connection: (1) Client sends \texttt{SYN} (Synchronize sequence number $x$), (2) Server replies with \texttt{SYN-ACK} (acknowledging $x+1$ and proposing sequence number $y$), (3) Client sends \texttt{ACK} (acknowledging $y+1$).\\[2mm]
\textbf{Q.22 (Ans: A)} When host $A$ needs to deliver an IP packet to local host $B$, it checks its local ARP cache. If missing, it broadcasts an ARP Request frame (\texttt{FF:FF:FF:FF:FF:FF}) asking "Who has IP $X.X.X.X$? Tell $Y.Y.Y.Y$". Host $B$ replies with a unicast ARP Reply frame containing its 48-bit hardware MAC address.\\[2mm]
\textbf{Q.27 (Ans: A)} In Symmetric cryptography (AES-128, AES-256), a single secret key encrypts plaintext into ciphertext and decrypts it back. While extremely fast and computationally efficient for large bulk data, it requires a secure key exchange mechanism (such as Diffie-Hellman or RSA) to share the secret key.
\end{solutionbox}
