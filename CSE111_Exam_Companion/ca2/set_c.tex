\subsection*{Detailed Technical Solutions}

\begin{solutionbox}[Key Cohorts \& Networking Explanations]
\textbf{Q.8 (Ans: A)} SQL Injection occurs when unvalidated user input is concatenated directly into SQL queries (e.g., \texttt{"SELECT * FROM users WHERE name = '" + input + "'"}). If an attacker inputs \texttt{' OR '1'='1'}, the query logic is hijacked. Parameterized queries pre-compile the SQL template on the database server; user parameters are treated strictly as data literals, rendering SQL code injection impossible.\\[2mm]
\textbf{Q.21 (Ans: A)} DHCP operates via the 4-step DORA process: (1) \textbf{Discover}: Client broadcasts to find DHCP servers; (2) \textbf{Offer}: Server unicasts/broadcasts an available IP lease; (3) \textbf{Request}: Client formally requests the offered IP; (4) \textbf{Acknowledge}: Server confirms the lease with subnet mask, gateway, and DNS configuration.\\[2mm]
\textbf{Q.22 (Ans: A)} In CIDR \texttt{/26}, 26 bits are assigned to the network, leaving $32 - 26 = 6\text{ bits}$ for hosts. Total IP slots $= 2^6 = 64$. Subtracting the Network Address (all host bits 0) and the Directed Broadcast Address (all host bits 1) leaves $64 - 2 = 62$ usable host addresses.\\[2mm]
\textbf{Q.24 (Ans: A)} Cryptographic hash functions like SHA-256 produce a fixed 256-bit digest. Key properties include: (1) Pre-image resistance (one-way property: given $h$, hard to find $m$ such that $H(m) = h$); (2) Second pre-image resistance (given $m_1$, hard to find $m_2$ such that $H(m_1) = H(m_2)$); (3) Collision resistance (hard to find any pair $m_1 \ne m_2$ with $H(m_1) = H(m_2)$); (4) Avalanche effect (a 1-bit change in input alters $>50\%$ of output bits).\\[2mm]
\textbf{Q.28 (Ans: A)} A VPN encapsulates standard IP packets inside an encrypted cryptographic wrapper (tunneling). Even if intermediate ISPs or hostile Wi-Fi attackers intercept packets, they see only encrypted ciphertext, safeguarding confidentiality and integrity.
\end{solutionbox}
