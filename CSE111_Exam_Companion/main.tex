\chapter{End-Term Examination Suite (Comprehensive)}
\label{chap:endterm}
\noindent
The End-Term Examination is the complete university-wide objective assessment evaluating all six core modules of Fundamentals of Computing and Information Technology:
\begin{itemize}[leftmargin=8mm]
    \item \textbf{Unit 1:} Computer System (Architecture, Memory Hierarchy, NVMe/SSD Storage, RAID)
    \item \textbf{Unit 2:} Operating System (Kernels, Boot Sequence, Process Scheduling, Virtual Memory, Compilation Lifecycle)
    \item \textbf{Unit 3:} Linux Operating System (FHS Structure, Permissions, Inodes, Bash Scripting, Virtualization)
    \item \textbf{Unit 4:} Cohorts and Technical Skill Sets (Web/Cloud/AI Tech Stacks, LeetCode/DSA, Portfolio Architecture)
    \item \textbf{Unit 5:} Computer Networks and Communication (OSI \& TCP/IP Models, Switching/Routing, IP Addressing, CIA Triad, Security)
    \item \textbf{Unit 6:} Version Control \& Modern AI Tools (Git Three-Tree Architecture, Branching/Merging, LLMs, Prompt Engineering)
\end{itemize}
Each comprehensive paper consists of \textbf{30 MCQs} evenly distributed across all units (Total = \textbf{30 Marks}, Time Allowed = \textbf{120 Minutes}, Negative Marking = \textbf{0.25 marks}). Complete Answer Keys and technical explanations are appended to every set.
