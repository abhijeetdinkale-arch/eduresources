\subsection*{Detailed Technical Solutions}

\begin{solutionbox}[Key Architectural \& Systems Explanations]
\textbf{Q.6 (Ans: A)} The IEEE 754 standard defines single-precision 32-bit floating-point numbers as: 1 bit for sign ($s$), 8 bits for exponent ($e$, with bias 127), and 23 bits for the normalized significand/mantissa ($m$), giving $V = (-1)^s \times 2^{e-127} \times (1.m)_2$.\\[2mm]
\textbf{Q.7 (Ans: A)} In Little-Endian ordering, the byte containing the least significant bits is stored at the lowest numerical memory address. For example, the 32-bit integer \texttt{0x12345678} at address \texttt{0x1000} is stored as: \texttt{0x1000: 78}, \texttt{0x1001: 56}, \texttt{0x1002: 34}, \texttt{0x1003: 12}.\\[2mm]
\textbf{Q.16 \& Q.17 (Ans: A)} A terminated process whose parent hasn't reaped it via \texttt{wait()} is a Zombie; it consumes only a process table slot (containing the exit code). An Orphan process has lost its parent (e.g. parent died first) and is immediately reparented to \texttt{init} (PID 1), which periodically reaps terminated children.\\[2mm]
\textbf{Q.22 (Ans: A)} Havender demonstrated that if every resource type $R_i$ is assigned a unique integer identifier $F(R_i)$, and processes are strictly required to request resources in an increasing numerical order ($F(R_i) < F(R_j)$), a circular dependency cycle cannot form, mathematically preventing Circular Wait.\\[2mm]
\textbf{Q.24 (Ans: A)} Best-Fit allocates the smallest hole that is big enough. While it minimizes wasted space in the allocated partition, it produces tiny leftover fragments that are often too small to be useful to any future process, exacerbating external fragmentation unless memory compaction is performed.
\end{solutionbox}
