\subsection*{Detailed Technical Solutions}

\begin{solutionbox}[Key Architectural \& Systems Explanations]
\textbf{Q.1 (Ans: A)} Harvard architecture features physically separate signal buses and memory address spaces for instructions and data, allowing instruction fetch and data read/write to execute concurrently without bus contention (eliminating the von Neumann bottleneck).\\[2mm]
\textbf{Q.5 (Ans: A)} An address bus with $N$ lines can generate $2^N$ unique binary addresses. For $N = 32$, $2^{32} = 4,294,967,296\text{ bytes} = 4\text{ GB}$.\\[2mm]
\textbf{Q.7 (Ans: A)} RAID 5 uses block-level striping with parity distributed across all member disks. Because parity blocks are computed across all data blocks in each stripe ($P = D_1 \oplus D_2 \oplus \dots$), a minimum of 3 physical drives is required to store at least two data blocks and one parity block per stripe.\\[2mm]
\textbf{Q.19 (Ans: A)} Legacy MBR stores partition records in a 64-byte partition table within the 512-byte Master Boot Record sector, restricting it to 4 primary partitions and 32-bit Logical Block Addressing ($2^{32} \times 512\text{ bytes} = 2.19\text{ TB}$). Modern GPT uses 64-bit LBAs (supporting $18\text{ Exabytes}$), provides up to 128 partitions by default, and includes a backup partition header at the end of the disk with CRC32 checksums.\\[2mm]
\textbf{Q.22 (Ans: A)} Thrashing occurs when the working sets of active processes exceed the physical memory capacity. The OS repeatedly encounters page faults, queuing page swaps to disk while the CPU remains underutilized, causing system throughput to collapse.\\[2mm]
\textbf{Q.28 (Ans: A)} The compiler emits relocatable object modules containing unresolved symbol references (e.g., calls to \texttt{printf} or functions defined in external source files). The Linker inspects the symbol tables, resolves external symbol addresses, links static libraries, and stitches together segments into a single cohesive executable binary.
\end{solutionbox}
