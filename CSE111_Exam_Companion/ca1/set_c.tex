\subsection*{Detailed Technical Solutions}

\begin{solutionbox}[Key Architectural \& Systems Explanations]
\textbf{Q.4 (Ans: A)} In fully associative mapping, any block of main memory can be loaded into any available cache line. This eliminates conflict misses entirely, but requires an associative (content-addressable) comparison where every cache line tag is evaluated simultaneously in parallel by dedicated comparator circuits.\\[2mm]
\textbf{Q.7 (Ans: A)} RAID 10 (or $1+0$) is a nested RAID level where data is first mirrored across disk pairs (RAID 1) and those mirrored sets are then striped (RAID 0). This provides fault tolerance against drive failure in each mirror pair without the parity computation overhead of RAID 5/6.\\[2mm]
\textbf{Q.18 (Ans: A)} SJF scheduling minimizes average waiting time because scheduling a job with a shorter execution burst ahead of a longer one reduces the waiting time of the shorter job by the duration of the long job, while increasing the long job's wait by only the short duration, mathematically minimizing $\sum W_i$.\\[2mm]
\textbf{Q.21 \& Q.22 (Ans: A)} Belady's Anomaly demonstrates that FIFO is not a stack algorithm; the set of pages in a frame buffer of size $k$ is not necessarily a subset of the pages in a frame buffer of size $k+1$. Increasing frames can cause early-evicted pages to miss during subsequent loops, increasing page faults.\\[2mm]
\textbf{Q.23 (Ans: A)} A page size of $4\text{ KB} = 4096\text{ bytes} = 2^{12}\text{ bytes}$. The offset within a page requires $\log_2(4096) = 12\text{ bits}$. In a 32-bit address, the remaining $32 - 12 = 20\text{ bits}$ are used for the Virtual Page Number (VPN), allowing $2^{20} \approx 1\text{ million}$ virtual pages.
\end{solutionbox}
