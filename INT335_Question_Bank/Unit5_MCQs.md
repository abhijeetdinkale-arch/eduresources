### Questions

**Q1. What is the primary purpose of user testing in Design Thinking?**
A) To prove to management that the design is flawless
B) To observe real user behavior and identify usability defects, confusion, and invalid assumptions
C) To grade the intelligence of the user
D) To sell subscriptions to test participants

**Q2. What is the fundamental difference between Usability Testing and Design Validation?**
A) Usability testing checks if the interface works efficiently; validation checks if it solves the right user problem
B) Usability testing is done by developers; validation is done by accountants
C) Usability testing requires paper; validation requires code
D) There is no difference; they are exact synonyms

**Q3. Which of the following best exemplifies the "Show, Don't Tell" testing approach?**
A) Presenting a 30-minute PowerPoint pitch explaining why the app is easy to use
B) Handing the user a prototype with a task scenario and observing their actions silently
C) Writing an instruction manual and reading it aloud to the user
D) Showing a promotional video of the product

**Q4. During a neutral user testing session, what should the facilitator say when a user asks, "Should I click this button?"**
A) "Yes, that is the correct button!"
B) "What do you think will happen if you click it?"
C) "No, don't click that, it's wrong."
D) "Let me click it for you."

**Q5. Why is it important to tell the participant: "We are testing the product, not you"?**
A) To protect the company from legal liability
B) To reduce participant anxiety and ensure they do not feel at fault when design errors occur
C) To prevent the participant from asking for money
D) Because participants are not allowed to make mistakes

**Q6. What makes a user testing Task Scenario effective?**
A) It specifies every button and menu name in exact order
B) It provides a realistic goal and context without dictating specific interface steps
C) It has no defined end goal
D) It can be completed in less than one second

**Q7. Which of the following is a POORLY constructed task scenario?**
A) "Find a pair of running shoes under ₹2,000 and proceed to the shipping screen."
B) "Click the search bar, type 'shoes', click filter, select 'under 2000', and tap 'Add to Cart'."
C) "You need to book a flight to Mumbai for next Monday morning. Show how you would do that."
D) "Check your account balance and download last month's statement."

**Q8. What is the "Think-Aloud Protocol" in usability testing?**
A) The facilitator constantly explains what the software is doing
B) The participant verbalizes their thoughts, expectations, and hesitations aloud while performing the task

D) The participant recites the user manual from memory

**Q9. Which quadrant of the Feedback Capture Matrix records constructive criticisms and unmet user wishes?**

**Q10. In a Feedback Capture Matrix, where does a user's statement *"Is international shipping included in this price?"* belong?**

**Q11. How does Customer Experience (CX) differ from Usability (UI/UX)?**

**Q20. When an error occurs on a form, what is the best UX practice for displaying error messages?**
