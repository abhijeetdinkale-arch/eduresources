# INT335 Question Bank
## Unit 2: Empathy, Observation and Problem Identification (30 MCQs)

---

### Questions

**Q1. What is empathy in the context of Design Thinking?**
A) Feeling pity or sympathy for users
B) The deep understanding of user feelings, motivations, behaviors, and unmet needs
C) Selling products using emotional advertisements
D) Guessing what users want based on designer intuition

**Q2. Which statement correctly differentiates a user "need" from a "solution"?**
A) "Users need an iPhone app" is a need; "Faster communication" is a solution
B) "Users need timely bus arrival info" is a need; "A mobile GPS tracker" is a solution
C) Needs and solutions are identical terms in design thinking
D) A solution is always identified before the user need

**Q3. What is "Computational Empathy" in software engineering?**
A) Giving computers feelings and consciousness
B) Designing systems that adapt gracefully to user context, errors, and emotional states
C) Calculating mathematical probabilities of human emotions
D) Replacing human customer support agents with chatbots

**Q4. Qualitative user research primarily aims to answer which question?**
A) "How many users clicked the button?"
B) "What is the average transaction value?"
C) "Why and how do users experience this problem?"
D) "What percentage of users are on iOS?"

**Q5. What is "Data Triangulation" in user research?**
A) Surveying exactly three users
B) Cross-verifying findings using multiple independent research methods and data sources
C) Arranging interview transcripts in triangular shapes
D) Using three different chart types in a presentation

**Q6. What does the "E" stand for in the AEIOU observation framework?**
A) Emotion
B) Environment
C) Evaluation
D) Efficiency

**Q7. In the AEIOU framework, "Interactions" refers to:**
A) Building relationships between project managers
B) Exchanges between person-to-person, person-to-device, or person-to-object
C) Social media marketing campaigns
D) Network server communications

**Q8. In user interviews, why are open-ended questions preferred over closed-ended questions?**
A) They elicit rich stories, past behaviors, and detailed context rather than simple "Yes/No"
B) They take much less time to administer
C) They are easier to grade mathematically
D) They prevent participants from talking too much

**Q9. Which of the following is an example of a LEADING question that should be AVOIDED?**
A) "Tell me about the last time you booked a doctor's appointment."
B) "What challenges did you face during your recent online order?"
C) "Don't you agree that our new checkout screen is very fast and helpful?"
D) "How did you feel when the payment failed?"

**Q10. The "Laddering" or "5 Whys" technique is primarily used to:**
A) Count the number of steps in a software flow
B) Uncover deep underlying root causes and emotional drivers behind a surface behavior
C) Grade user intelligence
D) Prolong the duration of an interview session

**Q11. What is an "Explicit Need"?**
A) An unspoken subconscious desire
B) A directly verbalized and clearly stated user requirement
C) A requirement that violates government regulations
D) An engineering specification hidden in code

**Q12. What is an "Implicit (Latent) Need"?**
A) An unstated expectation inferred through observing user workarounds, body language, and hesitation
B) A feature written in the user manual
C) A bug reported on an official feedback form
D) A need that is impossible to satisfy

**Q13. When a user has to enter the exact same shipping address across 4 different checkout screens, what type of pain point is this?**
A) Financial pain point
B) Time / Process pain point
C) Aesthetic pain point
D) Environmental pain point

**Q14. Hidden delivery charges revealed only on the final payment page create which type of user pain point?**
A) Process pain
B) Financial pain
C) Technical pain
D) Physical pain

**Q15. A User Persona in Design Thinking should be created based on:**
A) A designer's personal assumptions and stereotypes
B) Empirical data, user research patterns, behaviors, and motivations

**Q16. What is the primary difference between a Primary Persona and a Secondary Persona?**

**Q17. Which of the following is NOT one of the four main quadrants of a standard Empathy Map?**

**Q28. An actionable design insight is best described as:**

B) A statistical graph showing website traffic

**Q29. What type of pain point occurs when a user feels anxious and embarrassed because an ATM display exposes their account balance to everyone in line?**

### Answer Key & Explanations

| Question | Correct Answer | Explanation |
| :---: | :---: | :--- |
| **Q1** | **B** | Empathy is understanding the user's emotions, experiences, and implicit needs from their perspective. |
| **Q2** | **B** | Needs are underlying goals/outcomes; solutions are specific implementations. |
| **Q3** | **B** | Computational empathy designs software that adapts to human context, cognitive load, and emotions. |
| **Q4** | **C** | Qualitative research explores the rich "Why" and "How" behind human behavior. |
| **Q5** | **B** | Triangulation compares multiple distinct research methods to validate findings. |
| **Q6** | **B** | In AEIOU: Activities, Environments, Interactions, Objects, Users. |
| **Q7** | **B** | Interactions cover exchanges between humans, devices, and physical objects. |
| **Q8** | **A** | Open-ended questions allow participants to share realistic stories and unprompted context. |
| **Q9** | **C** | Leading questions nudge the participant toward a desired positive answer and introduce heavy bias. |
| **Q10** | **B** | Laddering (5 Whys) drills down from superficial actions to root motivations. |
| **Q11** | **B** | Explicit needs are directly stated and clearly communicated by users. |
| **Q12** | **A** | Implicit needs are unstated desires uncovered through observations and workarounds. |
| **Q13** | **B** | Re-entering identical information is a classic time and workflow process friction. |
| **Q14** | **B** | Unexpected costs and hidden pricing friction represent financial pain points. |
| **Q15** | **B** | Personas must be grounded in real behavioral research data, not designer stereotypes. |
| **Q16** | **B** | Primary personas represent the core user whose needs must be satisfied first without compromise. |
| **Q17** | **C** | Empathy map quadrants are Says, Thinks, Does, and Feels (plus Pains & Gains). |
| **Q18** | **C** | "Does" captures observable physical actions, workflows, and behavioral adaptations. |
| **Q19** | **A** | People often say what sounds good or polite, but their actual behavior reveals true needs. |
| **Q20** | **B** | A POV statement synthesizes User + Need + Surprising Insight. |
| **Q21** | **B** | "How Might We" questions reframe problem insights into constructive ideation prompts. |
| **Q22** | **B** | Good HMWs strike a balance: broad enough for variety, narrow enough for actionable focus. |
| **Q23** | **C** | Physical artefacts, cheat-sheets, and improvised tools fall under 'Objects'. |
| **Q24** | **B** | Neutral observation without interrupting or correcting yields authentic behavioral data. |
| **Q25** | **B** | Respecting privacy, gaining informed consent, and protecting participants are ethical imperatives. |
| **Q26** | **B** | Workarounds signal that existing official tools fail to satisfy a crucial user need. |
| **Q27** | **B** | Quantitative data tests the scale and frequency of qualitative insights. |
| **Q28** | **C** | Insights go beyond surface facts to explain the underlying "Why". |
| **Q29** | **B** | Anxiety, vulnerability, and embarrassment are emotional/psychological pain points. |
| **Q30** | **B** | Archetypes represent behavioral patterns and shared mental models across user groups. |
