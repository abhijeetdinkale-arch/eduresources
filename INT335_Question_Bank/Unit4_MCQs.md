# INT335 Question Bank
## Unit 4: Product Design and Prototyping (30 MCQs)

---

### Questions

**Q1. What is the core definition of a prototype in Design Thinking?**
A) A finished product ready for mass commercial distribution
B) A testable representation of an idea designed to answer specific questions and test assumptions
C) A legal patent document
D) A financial balance sheet

**Q2. What does the prototyping philosophy "Fail early, fail cheaply" mean?**
A) Intentionally destroying products to claim insurance
B) Uncovering critical design flaws in low-cost prototypes before expensive production begins
C) Giving up on projects at the first sign of trouble
D) Lowering product prices below production costs

**Q3. Which of the following is a characteristic of a LOW-FIDELITY prototype?**
A) Real-time database connectivity
B) Hand-drawn paper sketches, cardboard models, and rough mockups
C) High-resolution animations and pixel-perfect branding
D) Production-grade materials

**Q4. When should a design team primarily choose a Low-Fidelity prototype?**
A) When performing final regulatory compliance testing
B) Early in the design process to explore concepts, layout, and user flows rapidly
C) When measuring microsecond software server response latency
D) For investor demonstrations of fully functional algorithms

**Q5. What is a key advantage of High-Fidelity clickable prototypes?**
A) They can be created in 30 seconds with a pen
B) They allow realistic usability testing of detailed interactions and visual hierarchy
C) They require zero software tools
D) They prevent users from giving any negative feedback

**Q6. In a paper prototyping testing session, what role does the "Computer" play?**
A) Records video of the test on a laptop
B) A facilitator who silently swaps paper screens and pop-ups in response to user taps
C) Analyzes statistical metrics automatically
D) Explains the backend database code to the participant

**Q7. What is a "Storyboard" in user experience design?**
A) A screenplay written for a movie studio
B) A comic-strip style sequence of visual frames showing a user interacting with a product in real-world context
C) A task board showing software development sprint tickets
D) A list of customer testimonials

**Q8. What is the primary purpose of a Wireframe?**
A) Demonstrating color palettes and typography branding
B) Providing a grayscale skeletal layout that establishes content hierarchy and interface structure
C) Showing 3D electrical wiring diagrams of a building
D) Writing automated database queries

**Q9. Why are wireframes traditionally created in grayscale (black, white, gray)?**
A) Because color printing is too expensive
B) To keep focus strictly on layout, information hierarchy, and functionality without color distraction
C) Because computers cannot display color during early design
D) Because users dislike colorful interfaces

**Q10. In UI/UX wireframing conventions, what does a rectangle with an 'X' drawn across it represent?**
A) A delete button
B) An image or media placeholder
C) A broken database link
D) A closed window

**Q11. When should Radio Buttons be used in an interface wireframe?**
A) When a user can select multiple options simultaneously
B) When a user must choose exactly ONE option from a mutually exclusive list
C) For scrolling through long pages
D) For entering password text

**Q12. When should Checkboxes be used in a form?**
A) When a user may select zero, one, or MULTIPLE independent options
B) When only one binary choice is allowed
C) To trigger an immediate payment transfer
D) To submit a form to the server

**Q13. In a user flow diagram, what does an Oval (Terminator) shape represent?**
A) A decision point
B) The Start or End of a user workflow
C) A database storage unit
D) A clickable button

**Q14. In a user flow diagram, what does a Diamond shape represent?**
A) A user screen
B) A conditional decision point with branching paths (e.g., Yes / No)
C) The start of the process
D) A payment gateway

**Q15. What is the "Happy Path" (Primary Path) in a user flow?**
A) A colorful design theme
B) The default, error-free path where a user accomplishes their goal in the shortest direct sequence
C) A path that only children use
D) A marketing advertisement flow

**Q16. What is a Minimum Viable Product (MVP)?**
A) A stripped-down, broken version of a product that barely functions
B) The smallest version of a product that delivers real value to early adopters and enables maximum validated learning
C) A product with every single conceivable feature included
D) A product built with zero budget

**Q17. Which of the following is a classic analogy for an MVP?**
A) Delivering a single wheel, then an axle, then a car chassis
B) Delivering a skateboard first, then a bicycle, then a motorcycle, then a car (each stage is functional transport)
C) Delivering a car without brakes
D) Delivering an engine sitting on the floor

**Q18. What is a "Landing Page MVP"?**
A) An airport runway management software
B) A single web page describing a value proposition with a "Sign Up" button to gauge consumer demand before building
C) A fully coded e-commerce website with 50,000 products
D) A printed brochure handed out on the street

**Q19. What is a "Concierge MVP"?**
A) A software product for luxury hotel receptionists
B) Delivering the product service manually and personally behind the scenes to learn user needs before automating
C) An automated AI chatbot
D) A physical prototype made of titanium

**Q20. What is a "Wizard of Oz" prototype?**
A) A fantasy video game prototype
B) A prototype that looks completely automated to the front-end user but has humans manually operating backend tasks
C) A prototype that changes color dynamically
D) A prototype built using voice-over actors

**Q21. Why is testing with representative content (realistic text/prices) superior to "Lorem Ipsum" in wireframes?**
A) Lorem Ipsum is illegal in software design
B) Realistic content exposes actual spacing constraints, text overflow, and cognitive comprehension issues
C) Realistic text makes the wireframe look like a finished website
D) It prevents copyright violations

**Q22. Which prototype fidelity is best suited for testing complex micro-interactions, like swipe gestures and animated transitions?**
A) Paper sketch
B) Cardboard cutout
C) High-Fidelity interactive digital prototype
D) Static text document

**Q23. In digital product design, what does an "Empty State" design represent?**
A) A screen when the user's internet is disconnected
B) What a user sees when there is no data to display yet (e.g., "No orders placed yet"), guiding them to take action
C) A completely blank white screen due to a server crash
D) A logout confirmation screen

**Q24. What is the riskiest assumption for a startup building an on-demand laundry app?**
A) What shade of blue to use for the logo
B) Whether customers are willing to trust strangers to wash and return their clothes reliably
C) Whether to use React or Angular for the web frontend
D) The font size of the copyright notice

**Q25. How many user testing participants are typically recommended by usability expert Jakob Nielsen for discovering ~85% of usability errors in a prototype?**
A) 100 users
B) Exactly 5 users per target user group
C) 1,000 users
D) Only 1 user

**Q26. What does "Traceability" mean in product design?**
A) Tracing drawings on transparent paper
B) The ability to track every wireframe component and feature back to a validated user need and requirement
C) Recording user GPS locations
D) Following competitors' design styles

**Q27. In wireframing, what is the role of an "Annotation"?**
A) Artistic decoration in the margins
B) Numbered descriptive notes explaining dynamic behaviors, validation rules, and error states
C) User comments on social media
D) Software pricing details

**Q28. Which of the following is an example of an Alternate Path in a checkout user flow?**
A) User enters address $\rightarrow$ enters card $\rightarrow$ payment succeeds
B) User's credit card fails $\rightarrow$ system prompts for another payment method $\rightarrow$ user retries
C) User searches product $\rightarrow$ views product
D) User opens app $\rightarrow$ logs in

**Q29. What is the main danger of building a High-Fidelity prototype too early in a project?**
A) It uses too much electricity
B) Teams become emotionally attached to the visual polish and resist making fundamental structural changes
C) Users refuse to test beautiful prototypes
D) High-fidelity prototypes cannot be shared online

**Q30. What constitutes a complete, testable MVP hypothesis?**
A) "We believe [target user] has [problem], and will achieve [outcome] using [feature/solution], measured by [metric]."
B) "We believe our app will make millions of dollars by next month."
C) "We believe everyone in the world needs our new software."
D) "We believe technology is the future of business."

| Question | Correct Answer | Explanation |
| :---: | :---: | :--- |
| **Q1** | **B** | A prototype is an exploratory learning tool to test specific assumptions. |
| **Q2** | **B** | Early cheap failures reveal wrong assumptions before major capital is committed. |
| **Q3** | **B** | Lo-Fi prototypes are quick, rough representations like paper sketches and cardboard. |
| **Q4** | **B** | Lo-Fi is ideal early on for exploring structures, workflows, and core concepts. |
| **Q5** | **B** | Hi-Fi prototypes provide realistic interaction for testing fine UI and usability details. |
| **Q6** | **B** | In paper prototyping, the "Computer" physically manipulates paper states based on user actions. |
| **Q7** | **B** | A storyboard visually illustrates the user journey and context across comic-like panels. |
| **Q8** | **B** | Wireframes establish structural layout, visual hierarchy, and interface functional zones. |
| **Q9** | **B** | Grayscale keeps feedback focused on structure and function rather than subjective color debates. |
| **Q10** | **B** | A crossed rectangle is the universal design blueprint placeholder for images/video. |
| **Q11** | **B** | Radio buttons represent single-choice mutually exclusive selections. |
| **Q12** | **A** | Checkboxes allow zero, one, or multiple independent selections. |
| **Q13** | **B** | Ovals (terminators) denote the starting and ending points of a flowchart. |
| **Q14** | **B** | Diamond shapes represent conditional decision logic (e.g., Is user logged in?). |
| **Q15** | **B** | The happy path is the primary frictionless route to task completion. |
| **Q16** | **B** | An MVP is the leanest functional product that delivers core value and generates learning. |
| **Q17** | **B** | An MVP must provide functional value at every stage (skateboard $\rightarrow$ car). |
| **Q18** | **B** | Landing page MVPs test market demand and click interest before writing code. |
| **Q19** | **B** | Concierge MVPs deliver services manually to learn direct customer needs. |
| **Q20** | **B** | Wizard of Oz prototypes simulate automated backends with hidden manual human labor. |
| **Q21** | **B** | Real content exposes actual text wrapping, button sizing, and cognitive clarity. |
| **Q22** | **C** | Hi-Fi digital prototypes are required to test animated transitions and responsive gestures. |
| **Q23** | **B** | Empty states guide first-time users when no data exists yet. |
| **Q24** | **B** | Customer trust in handing over laundry is the fundamental value assumption. |
| **Q25** | **B** | Jakob Nielsen's research showed 5 users uncover ~85% of usability issues. |
| **Q26** | **B** | Traceability connects UI components directly back to user requirements. |
| **Q27** | **B** | Annotations document dynamic behavior, data validation, and logic for developers. |
| **Q28** | **B** | Payment retry/recovery represents an alternate/exception flow path. |
| **Q29** | **B** | High early polish causes sunk cost fallacy and attachment to flawed structures. |
| **Q30** | **A** | A structured hypothesis links user, problem, proposed solution, and measurable metric. |
